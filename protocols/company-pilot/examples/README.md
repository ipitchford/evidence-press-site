# Synthetic examples

The test runner constructs a deterministic fictional allocation and fictional
roster outcomes in memory. No generated assignment or plausible-looking outcome
numbers are shipped, because either could be mistaken for company evidence.

Run the public example input only to inspect output on screen. A live assignment
must use a frozen non-synthetic task bank, frozen run-ready plan, private
cryptographic seed, and an ignored working path under company-pilot/assignments/.
