Cosine configurations resist every small tilt. An Evidence Press briefing for the eighteenth of October, twenty twenty-six. Imagine several bell-shaped random quantities, each with the same variance. On every trial, keep the one closest to zero. How should their correlations be arranged to make this minimum small? A proposed answer uses equally spaced directions in a plane. But checking only planar arrangements misses a crucial possibility: perhaps tilting those directions out of the plane improves the result. This paper proves that sufficiently small tilts do not. For any number of coordinates at least three, and any moment order greater than one, the cosine configuration is a strict local minimum, including changes that increase the covariance rank. The proof separates changes to the angles from changes perpendicular to the plane. A signed cycle describes the latter. Its only zero-cost motions rotate the entire arrangement; all genuine nearby changes have a positive quadratic cost. Moving boundaries between the smallest coordinates are included in the calculation. This is local stability, not a global solution. No explicit neighbourhood radius is certified. A distant configuration might still do better. In fact, for four coordinates, independence is another strict local minimum with a higher value. That explains why an optimiser stopping successfully cannot settle the conjecture. The package provides the written proof, finite algebra checks, numerical evaluators and saved searches, including unsuccessful runs. These checks do not replace the universal argument, and the stronger global stochastic conjecture remains unresolved. This is an anonymous, AI-assisted, unrefereed candidate.
