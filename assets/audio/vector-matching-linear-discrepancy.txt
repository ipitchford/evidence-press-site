How fair can a pairing be? An Evidence Press briefing. Suppose n workers must be paired with n tasks, one each, and every possible pairing has one of k colours, standing for categories. A fair assignment would use each colour in proportion to how common it is. A random assignment gets this right on average, but its colour counts wobble by amounts that grow with n. Can some assignment be off by an amount that depends only on the number of colours? Lawrence Hollom showed that it can, with an error of four to the power k squared, and in 2026 Hogan, Scott and Tsarev reduced this to order k squared. This paper reduces it to seventeen k: linear in the number of colours. It also allows any vector labels, measured in any k-dimensional norm, and any fractional target, not just the uniform one. For arbitrary targets, order k cannot be improved: a simple example forces an error of k over two. For the uniform target, the truth lies between about the square root of k and seventeen k, and a square-root conjecture remains open. The key idea is to stop rounding pieces one at a time. The leftover fractional parts of the solution form paths. The paper lays all the paths end to end on one line and cuts them all at once, with a necklace-splitting style lemma that allows a different fraction on each piece while using few cuts in total. Consequences include linear bounds for colour-balanced matchings, spanning forests, Hamilton cycles and hypergraph matchings, and a school-assignment result where total capacity overflow for g groups is at most eight g minus one, instead of order g squared. These are existence results: no efficient algorithm is claimed. Every result has a written proof, and a script makes over two million exact checks of the finite bookkeeping.
