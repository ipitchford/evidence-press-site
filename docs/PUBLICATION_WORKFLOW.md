# Zero-quality-loss publication workflow

Evidence Press optimises publication by removing repeated execution and misordered gates, not by weakening review.

## Required sequence

1. Register the attempt and intended assurance target before substantive work.
2. Run the deterministic research baseline: replay, tests, manifests, documents, licences, citations and claim-to-evidence checks.
3. Run substantive independent-role review: Editor-in-Chief, methodology, domain, applications or cross-disciplinary, and Devil's Advocate, followed by a separate synthesis.
4. Repair every blocking finding and rerun the affected deterministic checks.
5. Freeze a publication-ready archive and bind the passed preflight receipt to its SHA-256.
6. Run one confirmation review against that exact frozen hash. Minor or Major means hold for repair; an unresolved Critical Devil's Advocate finding forbids acceptance.
7. Reserve and apply final DOI, tag, archive and citation identity once, then run the final identity gate.
8. Verify that the frozen commit is green. A tag pointing to the same already-green SHA does not need to repeat an expensive scientific replay.
9. Submit one preflighted site change containing the reader page, machine metadata, media, graph and ledger updates.
10. For a new URL, perform the unavoidable post-deployment live-readback and publication-ledger cycle. A third site cycle is exceptional and requires a recorded defect.
11. Close only from receipts: DOI resolution, GitHub release assets and hashes, canonical HTML and JSON, audio and art, source identity, public ledger and canonical-domain convergence.

## Gates that are never removed

- exact scientific or computational replay required by the research package;
- semantic bridges between statement, implementation and certificate;
- substantive adversarial and domain review;
- licence, rights, citation and provenance checks;
- manifest, archive, DOI, tag and commit identity checks;
- public URL preservation, deployment readback and canonical-domain convergence;
- explicit separation of producer replay, independent reproduction, formal verification, specialist review and peer review.

## Time accounting

Research assurance time and site-publication/readback time are reported separately. This makes bottlenecks visible without making either clock look like evidence for the other. The target is a two-and-a-half-hour end-to-end path for a clean moderate release; four hours is a hard audit threshold, not permission to skip a gate.
