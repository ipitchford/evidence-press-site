Decision: **retain and amend**, not replace. Reviewer: Codex, within the

Source reviewed: site commit `512025d`, the 14 October pilot design, frozen

## Findings and disposition

1. **Regression gate fails after routine publication.** The suite evaluates
   yesterday's frozen benchmark against today's changing catalogue. Preserve the
   benchmark; test refusal on changed inputs and exercise evaluation against an
   ephemeral fixture. Add this suite to CI: it was documented as required but
   absent from the workflow.
2. **Public state is stale.** The page says no discovery run has occurred and
   quotes old graph counts. Correct the narrative and rely on generated totals.
3. **Proposal display clips its own anchors.** Its centre-only viewBox excludes
   release nodes on the outer ring. Restore the complete viewport. Add state
   filtering and selectable titled search results with shareable URL state.
   The direct view initially omits unlinked nodes, which remain searchable and
   counted in missingness; this removes the crowded ring without deleting data.
4. **Burden uncertainty needs qualification.** The saved 11–109 range sums
   marginal Wilson endpoints; it is not a calibrated joint 95% interval. Some
   strata were censuses, so their model-labelled counts have no sampling
   uncertainty. Future summaries distinguish these cases and suppress aggregate
   projections with missing sample labels. Preserve historical outputs unchanged.
   Model error remains unquantified.
5. **The review threshold is unsupported as written.** Three signals yielded
   4/15 model accepts; four yielded 5/10, not a majority. Five and six yielded
   7/8 and 3/4 in this frozen sample. Prioritize these as a workload heuristic,
   not scientific credibility.
6. **Calibration is not ground truth.** Accepted thematic/method links need not
   pass the narrower shared-object rule. The reported 0.84 is agreement with
   recorded pairs, not validated scientific sensitivity.
