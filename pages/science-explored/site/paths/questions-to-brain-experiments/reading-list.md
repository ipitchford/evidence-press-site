# From a brain question to an experiment

1. [Lecture 1: Introduction](https://ocw.mit.edu/courses/9-13-the-human-brain-spring-2019/resources/lecture-1-introduction/) — Write one question about cognition that you would like evidence to answer; distinguish it from a general topic such as “vision”.
2. [Lecture 4: Cognitive Neuroscience Methods I](https://ocw.mit.edu/courses/9-13-the-human-brain-spring-2019/resources/lecture-4-cognitive-neuroscience-methods-i/) — Make a four-column table: question, measured quantity, comparison and remaining uncertainty. Add two methods from the lecture.
3. [Lecture 5: Cognitive Neuroscience Methods II](https://ocw.mit.edu/courses/9-13-the-human-brain-spring-2019/resources/lecture-5-cognitive-neuroscience-methods-ii/) — Add another approach and describe what complementary observation it could provide. Avoid claiming that one method settles every part of the question.
4. [Lecture 6: Experimental Design](https://ocw.mit.edu/courses/9-13-the-human-brain-spring-2019/resources/lecture-6-experimental-design/) — Read the linked experimental-design assignment. Sketch two linked experiments: the second should challenge an explanation still compatible with the first.
5. [Lecture 7: Category Selectivity, Controversies, and MVPA](https://ocw.mit.edu/courses/9-13-the-human-brain-spring-2019/resources/lecture-7-category-selectivity-controversies-and-mvpa/) — For two possible accounts, state a different prediction. Identify which observation would leave the accounts unresolved.
6. [Lecture 21: Brain Networks](https://ocw.mit.edu/courses/9-13-the-human-brain-spring-2019/resources/lecture-21-brain-networks/) — Rewrite one network claim to specify the evidence it would need. Identify an anatomical, statistical or task-related ambiguity you would investigate next.
