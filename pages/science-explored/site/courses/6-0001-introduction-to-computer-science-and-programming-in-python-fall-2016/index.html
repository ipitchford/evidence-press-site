6.0001 Introduction to Computer Science and Programming in Python. Fall 2016

  1. Lecture 1: What is Computation?

    Description: In this lecture, Dr. Bell introduces the theory of computation and explains some aspects of computational thinking. Programming languages are discussed, with an emphasis on basic Python syntax and data structures. Instructor: Dr. Ana Bell

  2. Shell vs. Editor

    Description: This in-class question explains the difference between the IDLE python environment and the shell. Instructor: Dr. Ana Bell

  3. Python vs. Math

    Description: This in-class question explains what mathematical statements are and are not valid in python. Instructor: Dr. Ana Bell

  4. Bindings

    Description: This in-class question explains variable bindings and the order of operations in python. Instructor: Dr. Ana Bell

  5. Lecture 2: Branching and Iteration

    Description: In this lecture, Dr. Bell introduces strings and indentation in Python, then discusses basic features of programmatic logic, such as branching, conditionals, iteration, and loops. Instructor: Dr. Ana Bell

  6. Strings

    Description: This in-class exercise demostrates working with strings in Python. Instructor: Dr. Ana Bell

  7. Comparisons

    Description: This in-class exercise demonstrates how conditionals and comparisons work in Python. Instructor: Dr. Ana Bell

  8. Branching

    Description: This in-class question demonstrates how conditional branching works in Python. Instructor: Dr. Ana Bell

  9. While Loops

    Description: This in-class question demonstrates While Loops in Python. Instructor: Dr. Ana Bell

  10. For Loops

    Description: This in-class question demonstrates For Loops and Break statements in Python. Instructor: Dr. Ana Bell

  11. Lecture 3: String Manipulation, Guess and Check, Approximations, Bisection

    Description: In this lecture, Dr. Bell discusses string manipulation, guess-and-check algorithms, approximate solution methods, and bisection search. Instructor: Dr. Ana Bell

  12. String Manipulations

    Description: This in-class question demonstrates the use of string indices in Python. Instructor: Dr. Ana Bell

  13. For Loops With Strings

    Description: This in-class question demonstrates how loops can be used with strings in Python. Instructor: Dr. Ana Bell

  14. Lecture 4: Decomposition, Abstraction, and Functions

    Description: In this lecture, Dr. Bell discusses program structuring, functions, specifications, scoping, and the difference between the “return” and “print” keywords in Python. Instructor: Dr. Ana Bell

  15. Function Calls

    Description: This in-class question demonstrates the differences between Print and Return statements in function construction in Python. Instructor: Dr. Ana Bell

  16. Functions as Arguments

    Description: This in-class question demonstrates how functions can be used as arguments in other functions in Python. Instructor: Dr. Ana Bell

  17. Lecture 5: Tuples, Lists, Aliasing, Mutability, and Cloning

    Description: In this lecture, Dr. Bell introduces compound data types, such as lists and tuples, and explains the concepts of aliasing, mutability, and cloning. Instructor: Dr. Ana Bell

  18. Tuples

    Description: This in-class question demonstrates tuples in Python, including the difference between tuples and strings. Instructor: Dr. Ana Bell

  19. Simple Lists

    Description: This in-class question demonstrates basic list operations in Python. Instructor: Dr. Ana Bell

  20. List Operations

    Description: This in-class exercise demonstrates more simple list operations in Python, including indexing, extending, sorting, and deleting. Instructor: Dr. Ana Bell

  21. List Aliasing / Mutation

    Description: This in-class exercise demonstrates list how aliasing affects other list operations in Python. Instructor: Dr. Ana Bell

  22. Lecture 6: Recursion and Dictionaries

    Description: In this lecture, Prof. Grimson introduces the concept of recursion and the Python dictionary data type. Instructor: Prof. Eric Grimson

  23. Lecture 7: Testing, Debugging, Exceptions, and Assertions

    Description: In this lecture, Dr. Bell discusses testing, debugging, and exceptions and assertion statements in Python. Instructor: Dr. Ana Bell

  24. Black Box and Glass Box Testing

    Description: This in-class question explains aspects of testing, including path-completeness and boundary conditions. Instructor: Dr. Ana Bell

  25. Errors

    Description: This in-class question demonstrates error codes in Python. Instructor: Dr. Ana Bell

  26. Exceptions

    Description: This in-class question demonstrates the use of exceptions in Python. Instructor: Dr. Ana Bell

  27. Lecture 8: Object Oriented Programming

    Description: In this lecture, Dr. Bell introduces Object Oriented Programming and discusses its representation in Python. Instructor: Dr. Ana Bell

  28. Class Definition

    Description: This in-class question demonstrates class definitions in Python. Instructor: Dr. Ana Bell

  29. Class Instance

    Description: This in-class question explains the how a class instance is initialized in Python. Instructor: Dr. Ana Bell

  30. Methods

    Description: This in-class exercise demonstrates class method construction in Python. Instructor: Dr. Ana Bell

  31. Method Call

    Description: This question explains the how a class method changes a attribute is altered in Python. Instructor: Dr. Ana Bell

  32. Special Methods

    Description: This in-class question demonstrates how a custom class method can be constructed in Python. Instructor: Dr. Ana Bell

  33. Lecture 9: Python Classes and Inheritance

    Description: In this lecture, Dr. Bell continues the discussion of Object Oriented Programming in Python, with an emphasis on data control, inheritance, and subclasses. Instructor: Dr. Ana Bell

  34. Getters and Setters

    Description: This in-class question explains how and why class attribute getters and setters are important in Python. Instructor: Dr. Ana Bell

  35. Subclass

    Description: This in-class question demonstrates how subclasses are constructed in Python. Instructor: Dr. Ana Bell

  36. Lecture 10: Understanding Program Efficiency, Part 1

    Description: In this lecture, Prof. Grimson introduces algorithmic complexity, a rough measure of the efficiency of a program. He then discusses Big “Oh” notation and different complexity classes. Instructor: Prof. Eric Grimson

  37. Lecture 11: Understanding Program Efficiency, Part 2

    Description: In this lecture, Prof. Grimson continues discussing different classes of algorithmic complexity, including logarithmic complexity, polynomial complexity, and exponential complexity. Instructor: Prof. Eric Grimson

  38. Lecture 12: Searching and Sorting

    Description: In this lecture, Prof. Grimson explains basic search and sort algorithms, including linear search, bisection search, bubble sort, selection sort, and merge sort. Instructor: Prof. Eric Grimson
