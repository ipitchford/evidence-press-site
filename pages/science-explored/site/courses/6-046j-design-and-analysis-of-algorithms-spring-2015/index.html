MIT 6.046J Design and Analysis of Algorithms, Spring 2015

  1. Lecture 1: Overview, Interval Scheduling

    Description: In this lecture, Professor Devadas gives an overview of the course and introduces an algorithm for optimal interval scheduling. Instructor: Srinivas Devadas

  2. Lecture 2: Divide & Conquer: Convex Hull, Median Finding

    Description: In this lecture, Professor Devadas introduces divide-and-conquer algorithms and problems that can be solved using divide-and-conquer approaches. Instructor: Srinivas Devadas

  3. Recitation 1: Divide & Conquer: Smarter Interval Scheduling, Master Theorem, Strassen's Algorithm

    Description: In this recitation, problems related to matrix multiplication and weighted interval scheduling are discussed. Instructors: Ling Ren

  4. Lecture 3: Divide & Conquer: FFT

    Description: In this lecture, Professor Demaine continues with divide and conquer algorithms, introducing the fast fourier transform. Instructors: Erik Demaine

  5. Recitation 2: B-trees

    Description: In this recitation, problems related to 2-3 Trees and B-Trees are discussed. Instructors: Amartya Shankha Biswas

  6. Lecture 4: Divide & Conquer: van Emde Boas Trees

    Description: In this lecture, Professor Demaine introduces the van Emde Boas Tree data structure and its uses. Instructors: Erik Demaine

  7. Lecture 5: Amortization: Amortized Analysis

    Description: In this lecture, Professor Demaine introduces analysis techniques for data structures, and the implementation of algorithms based on this analysis. Instructors: Erik Demaine

  8. Lecture 6: Randomization: Matrix Multiply, Quicksort

    Description: In this lecture, Professor Devadas introduces randomized algorithms, looking at solving sorting problems with this new tool. Instructors: Srinivas Devadas

  9. Recitation 4: Randomization: Randomized Median

    Description: In this recitation, problems related to Randomized Select and Randomized Quicksort are discussed. Instructors: Ling Ren

  10. Lecture 7: Randomization: Skip Lists

    Description: In this lecture, Professor Devadas continues with randomization, introducing skip lists as a randomized data structure. Instructors: Srinivas Devadas

  11. Lecture 8: Randomization: Universal & Perfect Hashing

    Description: In this lecture, Professor Demaine reviews hashing in the context of randomized algorithms. Instructors: Erik Demaine

  12. Recitation 5: Dynamic Programming: More Examples

    Description: In this recitation, problems related to dynamic programming are discussed. Instructors: Ling Ren

  13. Lecture 9: Augmentation: Range Trees

    Description: In this lecture, Professor Demaine covers the augmentation of data structures, updating common structures to store additional information. Instructors: Erik Demaine

  14. Lecture 10: Dynamic Programming: Advanced DP

    Description: In this lecture, Professor Devadas introduces the concept of dynamic programming. Instructors: Srinivas Devadas

  15. Lecture 11: Dynamic Programming: All-Pairs Shortest Paths

    Description: In this lecture, Professor Demaine covers different algorithmic solutions for the All-Pairs Shortest Paths problem. Instructors: Erik Demaine

  16. Lecture 12: Greedy Algorithms: Minimum Spanning Tree

    Description: In this lecture, Professor Demaine introduces greedy algorithms, which make locally-best choices without regards to the future. Instructors: Erik Demaine

  17. Recitation 6: Greedy Algorithms: More Examples

    Description: In this recitation, problems related to greedy algorithms are discussed. Instructors: Amartya Shankha Biswas

  18. Lecture 13: Incremental Improvement: Max Flow, Min Cut

    Description: In this lecture, Professor Devadas introduces network flow, and the Max Flow, Min Cut algorithm. Instructors: Srinivas Devadas

  19. Lecture 14: Incremental Improvement: Matching

    Description: In this lecture, Professor Devadas continues with the topic of network flow. Instructors: Srinivas Devadas

  20. Recitation 7: Incremental Improvement: Applications of Network Flow & Matching

    Description: In this recitation, problems related to Network Flow and Matching are discussed. Instructor: Ling Ren

  21. Lecture 15: Linear Programming: LP, reductions, Simplex

    Description: In this lecture, Professor Devadas introduces linear programming. Instructors: Srinivas Devadas

  22. Lecture 16: Complexity: P, NP, NP-completeness, Reductions

    Description: In this lecture, Professor Demaine introduces NP-completeness. Instructors: Erik Demaine

  23. Recitation 8: Complexity: More Reductions

    Description: In this recitation, problems related to NP-Completeness are discussed. Instructors: Amartya Shankha Biswas

  24. Lecture 17: Complexity: Approximation Algorithms

    Description: In this lecture, Professor Devadas introduces approximation algorithms in the context of NP-hard problems. Instructors: Srinivas Devadas

  25. Lecture 18: Complexity: Fixed-Parameter Algorithms

    Description: In this lecture, Professor Demaine tackles NP-hard problems using fixed-parameter algorithms. Instructors: Erik Demaine

  26. Recitation 9: Complexity: Approximations

    Description: In this recitation, problems related to approximation algorithms are discussed, namely the traveling salesman problem. Instructors: Amartya Shankha Biswas

  27. Lecture 19: Synchronous Distributed Algorithms: Symmetry-Breaking. Shortest-Paths Spanning Trees

    Description: In this lecture, Professor Lynch introduces synchronous distributed algorithms. Instructors: Nancy Ann Lynch

  28. Lecture 20: Asynchronous Distributed Algorithms: Shortest-Paths Spanning Trees

    Description: In this lecture, Professor Lynch introduces asynchronous distributed algorithms. Instructors: Nancy Ann Lynch

  29. Recitation 10: More Distributed Algorithms

    Description: In this recitation, problems related to distributed algorithms are discussed. Instructors: Ling Ren

  30. Lecture 21: Cryptography: Hash Functions

    Description: In this lecture, Professor Devadas covers the basics of cryptography, including desirable properties of cryptographic functions, and their applications to security. Instructors: Srinivas Devadas

  31. Lecture 22: Cryptography: Encryption

    Description: In this lecture, Professor Devadas continues with cryptography, introducing encryption methods. Instructors: Srinivas Devadas

  32. Recitation 11: Cryptography: More Primitives

    Description: In this recitation, problems related to cryptography are discussed. Instructors: Ling Ren

  33. Lecture 23: Cache-Oblivious Algorithms: Medians & Matrices

    Description: In this lecture, Professor Demaine introduces cache-oblivious algorithms. Instructors: Erik Demaine

  34. Lecture 24: Cache-Oblivious Algorithms: Searching & Sorting

    Description: In this lecture, Professor Demaine continues with cache-oblivious algorithms, including their applications in searching and sorting. Instructors: Erik Demaine
