MIT 16.687 Private Pilot Ground School, IAP 2019

  1. Lecture 1: Introduction to Private Pilot Ground School

    Description This first lecture introduced the background and course objectives of this three-day workshop of ground school for pilots. The main purpose is to help students prepare the FAA Private Pilot Knowledge Test. Instructor: Philip Greenspun, Tina Srisvas

  2. Lecture 2: Airplane Aerodynamics

    Description This lecture introduced the fundamental knowledge and basic principles of airplane aerodynamics. Instructor: Philip Greenspun, Tina Srisvastava

  3. Lecture 3: Learning to Fly

    Description This lecture introduced the details in acquiring the FAA Pilot Certificate. Instructor: Philip Greenspun, Tina Srisvastava

  4. Lecture 4: Aircraft Systems

    Description This lecture introduced different aircraft systems. Instructor: Philip Greenspun, Tina Srisvastava

  5. Lecture 5: Charts and Airspace

    Description This lecture focused on the aeronautical charts. Instructor: Philip Greenspun, Tina Srisvastava

  6. Lecture 6: The Flight Environment

    Description This lecture covered the topics of flying and landing at an airport. Instructor: Philip Greenspun, Tina Srisvastava

  7. Lecture 7: Navigation

    Description This lecture focused on how to navigate an airplane. Instructor: Philip Greenspun, Tina Srisvastava

  8. Lecture 8: Helicopter Aerodynamics

    Description This lecture focused on the aerodynamics of helicopters. Instructor: Philip Greenspun, Tina Srisvastava

  9. Lecture 9: Meteorology

    Description This lecture covered the basic weather theory, weather patterns, and related hazards. Instructor: Philip Greenspun, Tina Srisvastava

  10. Lecture 10: Communication and Flight Information

    Description This lecture covered topics of radar and ATC services, radio procedures, and sources of flight information. Instructor: Philip Greenspun, Tina Srisvastava

  11. Lecture 11: Aircraft Ownership and Maintenance

    Description This lecture covered aircraft maintenance, preventative maintenance, and alterations. Instructor: Philip Greenspun, Tina Srisvastava

  12. Lecture 12: Aircraft Performance

    Description This lecture discussed various factors affecting aircraft performance and how to predict performance for all flight phases. Instructor: Philip Greenspun, Tina Srisvastava

  13. Lecture 13: Interpreting Weather Data

    Description This lecture covered topics in understanding various weather reports and forecasts, and introduced graphic weather products. Instructor: Philip Greenspun, Tina Srisvastava

  14. Lecture 14: Human Factors

    Description This lecture discussed aeromedical factors and aeronautical decision-making. Instructor: Philip Greenspun, Tina Srisvastava

  15. Lecture 15: Flight Planning

    Description This lecture introduced various tools for flight planning. Instructor: Philip Greenspun, Tina Srisvastava

  16. Lecture 16: Seaplanes

    Description This lecture introduced different types of seaplanes. Instructor: Philip Greenspun, Tina Srisvastava

  17. Lecture 17: Small UAS Operations

    This lecture is with guest speaker, Michael Holzwarth. Description This lecture discussed the small unmanned aircraft systems and the related FAA regulations. Instructor: Michael Holzwarth

  18. Lecture 18: Weight and Balance

    Description This lecture discussed the topic of weight and balance during aircraft operation. Instructor: Philip Greenspun, Tina Srisvastava

  19. Lecture 19: Multi-Engine and Jets

    Description This lecture discussed the multi-engine aircraft, including the twin-turbojets. Instructor: Philip Greenspun, Tina Srisvastava

  20. Lecture 20: Flying at Night

    Description This lecture discussed the visual flight rules (VFR), issues and challenges when operating aircraft at night. Instructor: Philip Greenspun, Tina Srisvastava

  21. Lecture 21: Weather Minimums and Final Tips

    Description This last lecture discussed the more weather challenges a VFR pilot facing than an IFR pilot and had a final review of this three-day workshop. Instructor: Philip Greenspun, Tina Srisvastava

  22. Special Lecture: F-22 Flight Controls

    This is a special lecture with Randy Gordon. Description This lecture featured Lieutenant Colonel Randy Gordon to share experience in flying fighter jet. Instructor: Randy Gordon

  23. Special Lecture: The How and the Why of IFR

    This is a special lecture with Tina Srisvastava. Description This lecture discussed the instrument flight rules and instrument meterological conditions. Instructor: Tina Srisvastava

  24. Special Lecture: Oshkosh 2018

    This is a special lecture with Philip Greenspun. Description Philip Greenspun shared the EAA AirVenture at Oshkosh Wisconsin in July 2018. Instructor: Philip Greenspun
