Topic guide

How can a ray matrix predict the path through a camera lens?

Start with Lecture 2: Modern optics and lenses; ray-matrix operations; context enhanced imaging - Part 1

Represent a ray by its height and angle at a reference plane. Propagation and refraction each change that pair. Following the ray element by element makes the ordering of the optical system explicit.

Try it

Draw a ray through an air gap followed by a thin lens. Reverse the order, keeping the input ray fixed. Explain which intermediate height changes and why the final ray need not coincide.

Check your reasoning

In a uniform gap a ray changes height as it travels. A thin lens changes its direction according to the height at which it arrives. Interchanging the gap and lens can thus change the answer even if the two components themselves are unchanged.

Continue with Lecture 2: Modern optics and lenses; ray-matrix operations; context enhanced imaging - Part 2

The continuation of the optics lecture puts ray-matrix operations back into an imaging system. Identify the plane at which you would test focus.
