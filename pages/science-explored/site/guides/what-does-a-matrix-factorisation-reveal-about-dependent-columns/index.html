Topic guide

What does a matrix factorisation reveal about dependent columns?

Start with Elimination and Factorization A = CR

Watch the independent columns get selected during elimination. The coefficients describing the remaining columns tell you how to reconstruct all of the original data from a smaller set of columns.

Try it

Write a matrix whose third column is twice its first minus its second. Choose the independent columns and construct the coefficient matrix. Multiply back and check each column separately.

Check your reasoning

If the third column is twice the first minus the second, its coefficient column is (2, −1). Reconstruction tests the proposed factors. If the chosen first two columns are themselves dependent, the same construction cannot establish rank two.

Continue with Five Factorizations of a Matrix

The survey of five factorisations asks what changes when the factors are chosen for a different purpose.
