Topic guide

What must a probability model count as an outcome?

Start with 01.2 Sample Space

Start with the sample space before assigning probabilities. Describing a pair of coin tosses by the number of heads discards the order of the tosses and changes which events can be expressed.

Try it

List outcomes under the ordered-pair and head-count descriptions. Find one question both models can answer and one only the ordered model can answer. Assign probabilities and compare the result for exactly one head.

Check your reasoning

With two independent fair tosses, exactly one head has probability one half in either description. The head-count outcomes have probabilities one quarter, one half and one quarter. Treating those three outcomes as equally likely silently changes the model.

Continue with 01.4 Probability Axioms

The axioms lesson constrains the numbers assigned to these events. Check that probabilities add correctly for disjoint alternatives.
