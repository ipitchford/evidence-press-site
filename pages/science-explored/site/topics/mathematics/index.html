Topic guide

Why do thin films show different colours at different angles?

Watch for colour changes as viewing geometry changes. Light reflected at the two faces of a film travels along different optical paths. The relative phase depends on the paths and the wavelength.

Topic guide

What must a probability model count as an outcome?

Start with the sample space before assigning probabilities. Describing a pair of coin tosses by the number of heads discards the order of the tosses and changes which events can be expressed.

Topic guide

Why does compactness matter beyond ordinary Euclidean space?

Start with the Euclidean result and identify exactly where the ambient space enters. A familiar test involving closed and bounded sets can hide assumptions about the metric and dimension.

Topic guide

What does a matrix factorisation reveal about dependent columns?

Watch the independent columns get selected during elimination. The coefficients describing the remaining columns tell you how to reconstruct all of the original data from a smaller set of columns.

Topic guide

What does a computer need to represent a melody?

A recording, a list of pitches and a score preserve different properties of a performance. Follow the live coding example and ask what information must already have been extracted before the program can compare notes.
