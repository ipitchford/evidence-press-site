## Summary

Evidence Press does not run accounts, comments, advertising or analytics on this website, and it sets no cookies. It does not sell, rent or share personal data. This page also covers the private tool Evidence Press uses to manage its own YouTube channel.

*Effective 12 October 2026.*

## This website

- **No accounts, cookies or tracking.** The site is a set of static pages. It has no sign-in, no forms, no analytics scripts and no advertising, and it does not set cookies or use browser storage to identify visitors.
- **Hosting.** The site is served by Cloudflare Pages. Like any web host, Cloudflare processes technical request data (for example IP address, browser type and the page requested) in order to deliver pages and protect the service. Evidence Press does not receive or keep identifiable visitor logs. See the [Cloudflare privacy policy](https://www.cloudflare.com/privacypolicy/).
- **Embedded videos.** Release pages that include a video embed it from `youtube-nocookie.com`, YouTube's privacy-enhanced mode. YouTube receives data only when a visitor plays the video. See the [Google Privacy Policy](https://policies.google.com/privacy).
- **Links to other services.** Links to GitHub, Zenodo, Ko-fi and other sites lead to services with their own privacy policies; nothing is sent to them unless a visitor follows the link.

## The Evidence Press channel tool (YouTube API Services)

Evidence Press uses a private, single-user tool, "Evidence Press channel tools", to manage the Evidence Press YouTube channel. **This tool uses YouTube API Services.** Use of YouTube is governed by the [YouTube Terms of Service](https://www.youtube.com/t/terms), and Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

- **Who uses it.** Only the operator of the Evidence Press channel, acting on that channel. It is not offered to the public and acts on no one else's account.
- **What it accesses.** With the channel owner's consent through Google's sign-in, it reads the channel's own video details and YouTube Analytics reports (for example views, watch time and traffic sources), and it updates the channel's own video titles, descriptions, tags, thumbnails and playlists.
- **What it does not do.** It does not collect information about viewers, does not read or store comments or subscriber identities, does not post on anyone else's behalf, and does not use the data for advertising.
- **Storage.** Access tokens and retrieved channel data are stored only on the operator's own computer, with access restricted to the operator. Nothing is sold or shared with third parties. Data is kept only as long as needed to manage the channel and is deleted when no longer needed.
- **Revoking access.** Access can be revoked at any time from the Google account's [third-party connections page](https://myaccount.google.com/connections) ([Google security settings](https://security.google.com/settings/security/permissions)).
