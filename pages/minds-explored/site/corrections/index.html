Corrections

Help make the record more useful.

A title, source and concrete proposed change are more useful than a general rating.

This prepares a local text file; it does not send a message. Send the note through the Evidence Press website. In the project source, corrections are recorded as editorial overrides or withdrawals so a later refresh preserves them.

Report inaccessible or misleading resources individually. If an annotation is withdrawn, it is removed from the release count and future builds while the private change record retains the reason.
